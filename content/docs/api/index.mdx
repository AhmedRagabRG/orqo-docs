**Base URL** `https://app.orqo.site/api/v1` · **Auth** `Authorization: Bearer <token>` ·
**Spec** [`/openapi.json`](/openapi.json) (OpenAPI 3.1)

Each page shows the parameters, the request body, every response with its
schema, code samples in several languages and a playground. All endpoints
share the conventions in [Errors](/docs/errors), [Pagination](/docs/pagination)
and [Idempotency](/docs/idempotency).

<Callout type="warn" title="The playground makes real requests">
**Try in Playground** sends the request from your browser to
`https://app.orqo.site` with the token you paste after `Bearer ` in the
Authorization field. It acts on your organization like any other API call
(it can create contacts or send messages). Prefer a short-lived token, and
revoke it when you're done.
</Callout>
