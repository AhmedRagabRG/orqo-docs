The ORQO REST API gives your backend the same data your team sees in the ORQO
inbox: contacts and segments, WhatsApp campaigns, outbound messages,
conversations and analytics. Every request acts on one organization, the one
your API token belongs to.

```bash title="Your first request"
curl https://app.orqo.site/api/v1/me \
  -H "Authorization: Bearer $ORQO_API_TOKEN"
```

## Rules that hold for every endpoint

- **Base URL** `https://app.orqo.site/api/v1`. JSON in, JSON out.
- **Success** is `{"data": ...}`; lists add `"meta"` with a cursor ([Pagination](/docs/pagination)).
- **Failure** is `{"error": {"code", "message"}}`. Branch on `code`, never on `message` ([Errors](/docs/errors)).
- **Retries** of creating requests are safe with an `Idempotency-Key` header ([Idempotency](/docs/idempotency)).
- **Timestamps** are ISO 8601 in UTC (`2026-10-22T09:30:00Z`); IDs are integers.
- **Tokens are server-only.** Never ship an API token in a browser or mobile app.
